## Minimal example

```xml title="Config/WorkflowFiles/ImportObserved 1.00 default.xml"
<?xml version="1.0" encoding="UTF-8"?>
<workflow xmlns="http://www.wldelft.nl/fews" version="1.1">
  <activity>
    <runIndependent>true</runIndependent>
    <moduleInstanceId>ImportObservations</moduleInstanceId>
  </activity>
</workflow>
```

<Aside type="tip">
`<activity>` elements are direct children of `<workflow>` (no `<sequence>`
wrapper). Each runs a module via `<moduleInstanceId>` or nests a workflow via
`<workflowId>`. A module instance may appear only once across a workflow
(including nested). See the [task guide](/tasks/workflows/).
</Aside>
