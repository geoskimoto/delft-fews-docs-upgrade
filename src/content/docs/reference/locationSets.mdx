## At a glance

**Folder**

## Minimal example

```xml title="Config/RegionConfigFiles/LocationSets 1.00 default.xml"
<?xml version="1.0" encoding="UTF-8"?>
<locationSets xmlns="http://www.wldelft.nl/fews" version="1.1">
  <locationSet id="AllDischargeGauges">
    <locationId>RiverGauge_01</locationId>
    <locationId>RiverGauge_02</locationId>
  </locationSet>
</locationSets>
```

<Aside type="tip">
Members can also come from a `csvFile` / `esriShapeFile` / `geoJsonFile` /
`geoPackageFile` / `table`, or be selected dynamically with `constraints`. See
the [task guide](/tasks/locations/#part-2-grouping-with-location-sets).
</Aside>
