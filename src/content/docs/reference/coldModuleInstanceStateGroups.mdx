This page is the generated field list for `ModuleInstanceStateGroups.xml` —
named cold-state options a forecaster can pick from in the state-selection
dialog when a [module instance](/reference/moduleinstancedescriptors/) has no
usable warm state (first run, gap after downtime, or a deliberate reset).

## At a glance

<div class="field-list">

**Purpose**
: Declares one `defaultGroup` (always available), any number of
`additionalGroup`s, and — since 2017.02 — `seasonalGroup`s that are only
offered within a configured month/day window (e.g. a snowmelt-season cold
state).

**Folder**
: `Config/RegionConfigFiles/`

**Root element**
: `<coldModuleInstanceStateGroups>` (`version="1.0"`, required)

**Concept**
: See [The forecasting lifecycle](/concepts/lifecycle/) for cold vs. warm
state in general.

</div>

## Minimal example

```xml title="Config/RegionConfigFiles/ModuleInstanceStateGroups.xml"
<?xml version="1.0" encoding="UTF-8"?>
<coldModuleInstanceStateGroups xmlns="http://www.wldelft.nl/fews" version="1.0">
  <defaultGroup id="Default" name="Default cold state">
    <description>Standard cold start with no prior state</description>
  </defaultGroup>
  <seasonalGroup id="SnowmeltStart" name="Snowmelt season start">
    <description>Cold state tuned for the start of the snowmelt season</description>
    <season>
      <startMonthDay>--03-01</startMonthDay>
      <endMonthDay>--04-15</endMonthDay>
    </season>
  </seasonalGroup>
</coldModuleInstanceStateGroups>
```

## Gotchas

- `startMonthDay`/`endMonthDay` use XML's `gMonthDay` form: `--MM-DD` (note
  the leading `--`), not a plain `MM-DD` string.
- `defaultGroup` is **required** and singular — it's the fallback whenever no
  seasonal group matches the run's time zero. `additionalGroup` and
  `seasonalGroup` are both optional and repeatable on top of it.
- A `seasonalGroup`'s window (`startMonthDay`/`endMonthDay`) is evaluated
  against **run time zero**, not the state's own timestamp — configure the
  window around when you want the option *offered*, not when the underlying
  state data is representative of.
