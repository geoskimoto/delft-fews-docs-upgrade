This page is the generated field list for `RatingCurves.xml` — the
stage-discharge (H/Q) relationships that convert a measured water level into a
discharge (or vice versa). Core to any river forecasting system built on
gauge-derived flow.

## Minimal example

```xml title="Config/RegionConfigFiles/RatingCurves.xml"
<?xml version="1.0" encoding="UTF-8"?>
<ratingCurves xmlns="http://www.wldelft.nl/fews" version="1.1">
  <ratingCurve ratingCurveId="Gauge01_HQ">
    <location locationId="Gauge01"/>
    <ratingCurveType>LevelToFlow</ratingCurveType>
    <reversible>false</reversible>
    <ratingCurveTable>
      <ratingCurveTableRecord level="0.0" flow="0.0"/>
      <ratingCurveTableRecord level="1.0" flow="12.5"/>
      <ratingCurveTableRecord level="2.0" flow="48.0"/>
    </ratingCurveTable>
  </ratingCurve>
</ratingCurves>
```

## Gotchas

- `ratingCurveType` is `LevelToFlow` or `FlowToLevel` — it fixes the
  conversion **direction**; `reversible` is a separate flag for whether the
  same curve may also be used the other way round.
- A curve is `ratingCurveTable` **or** `ratingCurveEquation`, not both — pick
  the table form when you have measured gaugings, the equation form
  (power/parabolic/user-defined) when you have a fitted formula.
- `validPeriod` (repeatable) lets a rating shift over time — omit it and the
  curve is valid for all time, which is wrong for a channel that's been
  regraded or re-surveyed.
