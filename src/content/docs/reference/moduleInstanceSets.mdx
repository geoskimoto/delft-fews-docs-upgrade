This page is the generated field list for `ModuleInstanceSets.xml` — a small
lookup file that gives a single id to a group of
[module instance](/reference/moduleinstancedescriptors/) ids, so other config
can reference "all the import modules" (for example) instead of listing each
one.

## At a glance

<div class="field-list">

**Purpose**
: Groups module instance ids under one `moduleInstanceSetId`, listed either
explicitly (`moduleInstanceId`, repeated) or by wildcard pattern
(`moduleInstanceIdPattern`, using `*`/`?`).

**Folder**
: `Config/RegionConfigFiles/`

**Root element**
: `<moduleInstanceSets>` (`version="1.1"`, required)

**Depends on**
: The instances it lists must exist in [Module instance
descriptors](/reference/moduleinstancedescriptors/).

</div>

## Minimal example

```xml title="Config/RegionConfigFiles/ModuleInstanceSets.xml"
<?xml version="1.0" encoding="UTF-8"?>
<moduleInstanceSets xmlns="http://www.wldelft.nl/fews" version="1.1">
  <moduleInstanceSet id="AllRainfallForecasts" name="All rainfall forecast imports">
    <moduleInstanceIdPattern>*_Rainfall_Forecast</moduleInstanceIdPattern>
  </moduleInstanceSet>
</moduleInstanceSets>
```

## Gotchas

- Inside one `moduleInstanceSet`, `moduleInstanceId` and
  `moduleInstanceIdPattern` are a **repeated choice** — mix explicit ids and
  wildcard patterns in the same set if needed; the field reference lists both
  as top-level fields but they aren't required together.
